niixtube changes how YouTube behaves, so you see what you actually want to see.


Subscriptions-only home feed, sorted newest first — no algorithmic picks

Watched videos are dimmed instead of disappearing, so new ones stand out

Queue videos and let them play automatically, one after another

Shorts hidden everywhere

No more "Video paused. Continue watching?" popup

Plays the original audio track instead of an auto-dubbed one, when available

Shows video titles exactly as the uploader wrote them, not auto-translated


Every feature can be turned on or off individually in Settings.
